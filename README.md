# Abdallah Samy — Flutter Portfolio V5

Updates in this version:
- Skills/tools merged into the About section.
- Non-technical About content reduced.
- Main Flutter UI service shows price, duration, scope, out-of-scope and deliverables.
- Training projects show duration, technical scope and deliverables without pricing.
- Project visual placeholders added under `assets/projects/` for easy screenshot replacement.
- LinkedIn and GitHub calls-to-action made more prominent.

## Project screenshots
Replace these placeholder files with your own screenshots, or change their paths in `index.html`:
- `assets/projects/movie-project.svg`
- `assets/projects/bmi-project.svg`
- `assets/projects/todo-project.svg`

## LinkedIn project links
The project buttons currently use the public LinkedIn activity page because direct post URLs for all three projects were not available in the supplied portfolio files. Replace each project link in `index.html` with the direct post URL when available.

## Project screenshots
Each project now supports 3 gallery images. Replace these files in `assets/projects/` while keeping the same filenames (or update the paths in `index.html`):
- `movie-1.svg`, `movie-2.svg`, `movie-3.svg`
- `bmi-1.svg`, `bmi-2.svg`, `bmi-3.svg`
- `todo-1.svg`, `todo-2.svg`, `todo-3.svg`
You can use PNG/JPG/WebP instead; just change the file extensions in `index.html`.

## V7 updates
- Out-of-scope items are shown as paid add-ons with starting prices and a clear warning that they are not included in the $50 base package or base delivery time.
- Project screenshots now use a phone-style carousel. On desktop multiple screens remain visible, arrows/dots switch focus, and clicking a screen opens a full preview.
- To use your real screenshots, replace the files in `assets/projects/` while keeping the same filenames, or change the image `src` paths in `index.html`.
- Add-on prices are starting estimates; edit them in the `OUT OF SCOPE · PAID ADD-ONS` section if you want different commercial rates.


## V8 pricing/scope update
- Base package increased to **$90** for up to 3 responsive Flutter UI screens.
- Base scope is explicitly **front-end UI implementation only**.
- Local form fields/client-side validation can be included when present in the supplied design.
- REST APIs, Firebase/Firestore, authentication, push notifications, maps, payments, store publishing and redesign are paid add-ons and are not duplicated in the base scope.
- Add-on prices were rebalanced so they are proportionate to the new starting price.

## V9 project screenshot showcase
Project images now appear as a layered 3-phone device deck instead of a normal carousel. The focused screenshot stays in the center, the other screens sit behind it with perspective, and users can click, use arrows, keyboard arrows, or swipe on mobile. Clicking the focused phone opens the full-screen preview.

## V10 update — Service pricing tiers
The Services section now contains three clear packages: Basic ($90), Standard ($170), and Premium ($260), with scope, revisions, delivery, support and ideal-client positioning. Out-of-scope wording was updated so items included in higher tiers are not presented as universally excluded.

## V11 service pricing update
- Deliverables are now defined inside each package card instead of being shown as one shared deliverables list.
- Basic, Standard and Premium each show exactly what the client receives at that tier.
- Standard has a stronger visual treatment to make the "Most Popular" tier immediately noticeable.

## V12 updates
- Refined Basic, Standard and Premium deliverables so each package has a clear handoff list.
- Premium explicitly includes complete Flutter source code, APK, iOS-ready project files, repository/ZIP handoff, and expanded documentation.
- Pricing cards received a stronger visual hierarchy and a more prominent Standard / Most Popular treatment.
- Added a light/dark theme toggle. Dark mode is the default for first-time visitors; a visitor's manual choice is remembered locally.
